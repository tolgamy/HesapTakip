Üyelik başvurusu

Türkçe harf, rakam, nokta (.), tire (-) ve alt çizgi (_); boşluk kullanma. “admin” alınamaz.

iPhone, Android ve bilgisayarda nasıl kurulur?
  1. iPhone / iPad: Uygulamayı Safari'de aç → Paylaş (kareden yukarı ok) → Ana Ekrana Ekle → varsa Web Uygulaması Olarak Aç seçeneğini etkin bırak → Ekle.
  2. Android: Chrome'da aç → sağ üstteki üç nokta → Uygulamayı yükle veya Ana ekrana ekle.
  3. Windows / Linux: Chrome ya da Edge'de aç → adres çubuğundaki kurulum simgesi veya tarayıcı menüsü → Uygulamayı yükle.
  4. Mac: Safari'de Dosya → Dock'a Ekle; Chrome'da menüdeki uygulama yükleme seçeneğini kullan.

Finans kayıtları Cloudflare D1'de tutulur. Giriş bilgileri kasası ayrı bir şifreleme anahtarı kullanır; kart numarası ve CVV kaydetmeyin.
